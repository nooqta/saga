# Traceability Matrix

Display the traceability matrix showing how requirements map to features, stories, and their status.

## Pre-requisites

1. Check if `.saga/plan.json` exists
   - If not: "Please run `/saga plan` first to create the implementation plan."

2. Check if `.saga/srs.md` exists
   - If not: "Please run `/saga spec` first to generate the SRS."

## Display Process

### 1. Load Data

Read from:
- `.saga/srs.md` - Extract all FR-XXX and NFR-XXX requirements
- `.saga/plan.json` - Get stories with linkedRequirements and passes status
- `.saga/project.json` - Get PM configuration for issue links

Create a comprehensive traceability view:

### 3. Status Icons

| Icon | Meaning |
|------|---------|
| ✅ | Done/Passed |
| 🔄 | Work in Progress |
| ⏳ | Pending |
| ⚠️ | Gap (no story) |
| ❌ | Failed/Not covered |
| 🚫 | Blocked |

### 4. Detailed View Options

If user asks for details on a specific requirement:

```
FR-001: User Authentication

Status: ✅ Implemented
Feature: F-001 (Authentication System)
Story: US-001 (Implement login functionality)

Acceptance Criteria:
  ✅ Users can log in with email/password
  ✅ Session persists across page refreshes
  ✅ Invalid credentials show error message

Implementation:
  Files: src/auth/login.ts, src/components/LoginForm.tsx
  Commit: abc123
  PR/MR: #45

PM Issue: https://github.com/org/repo/issues/123
```

## Commands After Display

Suggest next actions:
```
Commands:
  /saga gaps      - Detailed gap analysis
  /saga status    - Execution progress
  /saga execute   - Start/continue implementation
  /saga diagram   - Generate UML diagrams
```
